# Acool_ou_Etanol_atv_react
Com a oscilação dos preços dos combustíveis, os motoristas sempre ficam em dúvida no posto. Existe uma regra matemática clássica: se o preço do litro do etanol for menor que 70% (0,7) do preço da gasolina, compensa abastecer com etanol; caso contrário, a gasolina é mais vantajosa.
